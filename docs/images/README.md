# Repository artwork

These are selected durable copies of native Marketing Studio captures from
19 October 2026. See [CAPTURE.md](../../CAPTURE.md) for reproduction and staging
details. Ships, water, lighting and effects come from the game; gameplay HUD and
guides are hidden. Asset and font licences remain in [CREDITS.md](../../CREDITS.md).

- `blackwater-hero.png`, `blackwater-combat.png`, `blackwater-flagship.png`:
  1920 × 1080 stills from `build/marketing_studio/`.
- `blackwater-cover.gif`: the existing optimized 630 × 500 cover, 75 frames,
  five seconds, repeating. Its source is `blackwater-cover-optimized.gif`.
- `blackwater-social-preview.png`: 1280 × 640 GitHub social card, composed from
  the hero still with the game's IM Fell English SC and Barlow Semi Condensed fonts.
  Navy margins preserve the full scene; cream title and brass footer match the game.

Raw takes and temporary review output stay in the ignored `build/` directory.
