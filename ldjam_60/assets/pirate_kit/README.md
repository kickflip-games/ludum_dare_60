# Pirate kit subset — Quaternius

Source bundle: https://poly.pizza/bundle/Pirate-kit-0q5ulmIYqQ

The three included models are **Small Ship**, **Cannon**, and **Rock**, by
**Quaternius**, downloaded from their official Poly Pizza model pages on
2026-10-17. Each individual page and the bundle identify the assets as
**CC0 1.0 Universal / Public Domain**. No account, payment, or separate
acceptance was required.

See `sources.json` for the exact model pages, official static download URLs,
and SHA-256 checksums. `CC0-1.0.txt` preserves the official license text from
https://creativecommons.org/publicdomain/zero/1.0/legalcode.txt.

The GLBs are unmodified, self-contained static models with embedded material
data. Godot applies scale, rotation, and placement at runtime. The Small Ship
is used for the player boat and wreck hulls; the Cannon faces starboard; the
Rock replaces hazard visuals. Existing collision shapes, shot direction,
muzzle position, and navigation remain independent of these visual models.

No downloaded scripts, tools, installers, or animation controllers are used.
Attribution is provided in the title screen and repository credits as a courtesy.
